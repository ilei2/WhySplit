# WhySplit
Why Split

## Instructions on how to run

Initialize packages with "npm install".

Run "npm start" to begin service. If successful, the terminal will provide the server endpoint.

To submit a query, use the following template and run on browser:

```
GET command:
http://localhost:XXXX/transaction/:id

(id is the unique object id assigned to a transaction)

TBD:
POST, PUT, DELETE operations
```
